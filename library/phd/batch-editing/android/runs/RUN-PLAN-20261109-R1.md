## Tool notes (Windows, this machine)
- Git Bash rewrites `/sdcard/...` paths: run device and adb commands with `MSYS_NO_PATHCONV=1`.
- `device-android.ts` cannot start Appium on Windows (it spawns `appium` without a shell, ENOENT). Appium runs on
  port 4724, started by the orchestrator; if `status` says it is not answering, start it with
  `appium --address 127.0.0.1 --port 4724` in the background, then `restart RFCW2198L7B`.
- Google Play Protect blocked the UiAutomator2 server install until the user turned USB app verification off
  (2026-11-10). If an install hangs again, screenshot the phone and stop with a BLOCKER.
- `launch` returns before the Launcher is drawn: `waitfor "Edit" --timeout 20` after it.
