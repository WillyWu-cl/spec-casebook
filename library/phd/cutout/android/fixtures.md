# Cutout Reset / Undo / Redo (Android) — what the phone needs before a run

What a run needs on the phone or the account, because none of it can be committed. Check it before the first segment;
a new row that needs a new photo or account state adds it here in the same draft.

## Phone, app and account
- Phone: Samsung Galaxy S23 (SM-S9110, adb serial RFCW2198L7B, Android 16, 1080 × 2340), on USB, Stay awake on, no
  PIN. A Pixel 8a is also on adb: always pass the serial.
- PhotoDirector for Android 20.19.0 (90201900), installed 2026-11-09 (user, 2026-11-10: run on the S23). The Launcher
  shows the Test Server labels. No TR named for this run.
- Tier: whatever the phone is on (Premium since the Batch Editing run, 「Hello VIP!」 in Mine). Record it at each
  segment start; the Cutout spec states no tier rule. Never buy, never type a password.
