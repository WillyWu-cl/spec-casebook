## Tool notes (Windows, this machine)
- Git Bash rewrites `/sdcard/...` paths: run device and adb commands with `MSYS_NO_PATHCONV=1`.
- Appium runs on port 4724 (already up). If `status` says it is not answering, start
  `appium --address 127.0.0.1 --port 4724` in the background, then `restart RFCW2198L7B`.
- `launch` returns before the Launcher is drawn: `waitfor "Edit" --timeout 20` after it.
- `device-android.ts hold X Y [s]` takes **seconds**. Two-finger rotate: `pinch` cannot rotate; use
  `adb shell input` is single-touch, so a rotate row that no command can do is Blocked `--as observability` with that
  reason (try the app's own rotate handle first, if the selected object shows one).
  **Update R1-a:** two-finger rotate works through Appium W3C actions:
  `node library/phd/cutout/android/recipes/rotate.mjs $(cat <run dir>/.session) 540 900 250 30 <hold ms>` (no handle exists).
